# LahoreCare — Hospital Appointment Website

A redesigned, Lahore-only hospital appointment website built with HTML, CSS and JavaScript.

## Design changes
- Completely new visual direction: warm editorial healthcare style
- Cream, deep green and terracotta palette
- No large hero circle / abstract orb
- No frosted glass / neon / futuristic wording
- Simple hospital-directory language
- Clean rectangular information panels and restrained borders
- Responsive layout designed to keep sections and controls separated

## Coverage
The directory contains 32 hospital available specialist profiles, all located in Lahore, across departments including:
Cardiology, Orthopedics, Dermatology, Pediatrics, Gynecology, Obstetrics, Neurology, Internal Medicine, ENT, Ophthalmology, Gastroenterology, Psychiatry, Urology, Endocrinology, Nephrology, Pulmonology, Rheumatology, Oncology, Nutrition & Dietetics, General Surgery, Plastic Surgery, Neurosurgery, Dentistry, Physiotherapy, Infectious Diseases, Family Medicine and General Physician.

## Run
Extract the ZIP and open `index.html` in VS Code. For the best development experience use the Live Server extension.

## Data note
All doctor/hospital names, qualifications, fees, ratings, phone numbers and schedules are hospital hospital data. Replace them with verified information before production use.

The appointment form currently saves requests to browser localStorage. A real hospital deployment should connect it to a secure backend/database and use verified provider information.
